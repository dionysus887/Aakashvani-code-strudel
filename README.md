# AAKASHVANI
This EP was inspired by Rupa Biswas' 'Disco Jazz', 'Revolver' by the Beatles, and 'Dark Side of the Moon' by Pink Floyd. I coded the whole thing in strudel since i had learnt about it recently.
It was really fun making this, and hence im giving out the code for everyone to see what the composition was like!
